Payment Integrity Data Platform

  • Optum
  • Scala, Apache Spark, Databricks

At Optum I build and run data pipelines for payment integrity and coordination of benefits. The platform processes healthcare claims data with Scala and Apache Spark on Databricks. The work covers ingestion, transformation, and delivery of the data that payment accuracy depends on.

State Assessment Platforms

  • Pearson
  • Java, Spring Boot

At Pearson I built backend services for ADAM, TestNav, and PearsonAccess Next, the platforms that deliver K to 12 state assessments. The systems run on Java and Spring Boot and support high volume student assessment delivery. I built and maintained the backend services these platforms run on.

Claimline Data Toolkit

  • Open Source
  • Spark, Scala, Python, Kafka

Claimline is an open source data quality and reconciliation toolkit for healthcare claims data, built with Spark and Scala. It runs validation rules over high volume claims data sets, flags mismatched and duplicate records, and produces reconciliation reports data engineers can act on. All sample data in the project is synthetic.
